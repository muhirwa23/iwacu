# eHanga - Online Shopping Platform

eHanga is a simple and responsive e-commerce website template built with HTML, CSS, and JavaScript.

## Features

- Responsive design that works on mobile, tablet, and desktop
- Shopping cart functionality
- Add/remove products from cart
- Update product quantities
- Calculate total price
- Checkout process

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Boxicons for icons

## Project Structure

```
eHanga/
├── css/
│   └── style.css
├── img/
│   └── (product images)
├── js/
│   └── main.js
├── index.html
└── README.md
```

## Setup and Installation

1. Clone the repository:
```
git clone https://github.com/muhirwa23/iwacu.git
```

2. Navigate to the project directory:
```
cd iwacu
```

3. Open `index.html` in your browser to view the website.

## Usage

- Click on the shopping bag icon on a product to add it to your cart
- Click on the cart icon in the header to view your cart
- Adjust quantities or remove items in the cart
- Click "Buy Now" to complete your purchase
